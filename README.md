Tauris Media - A premium portfolio website designed to showcase visual narratives in a way that feels more like experiencing a film than browsing a website. Every scroll tells a story, every transition is intentional, and every interaction is crafted to leave a lasting impression.

How I built it - I explored a wide range of Awwwards and Wix showcase websites to draw inspiration, particularly focusing on complex brand theming that leveraged brown-toned palettes and a bull mascot as a core brand influence. Through this research, I identified an effective design direction while also developing a deeper understanding of how to balance strong visual identity with optimized user experience.
From there, the project progressed through iterative stages of building and designing, followed by performance optimization, responsive engineering, and detailed visual and interaction polishing to ensure a refined final experience.

Tech Stack - This project is built using React 19 for a modern, component-driven architecture, Tailwind CSS 4 for rapid and consistent utility-first styling, and Framer Motion to deliver smooth, high-performance animations and transitions that enhance the overall user experience.

Key highlights - 
Intelligent Caching System - A custom-built caching mechanism preloads and stores assets efficiently. First-time visitors experience a controlled loading sequence, while returning users benefit from instant, cache-driven page loads.

Responsive Design - The layout is optimized for all screen sizes, with separate logic for mobile and desktop to ensure smooth performance, accurate calculations, and reliable touch interactions.

Micro-Interactions - Subtle animations, guided progress indicators, smooth page transitions, and refined hover states are implemented using Framer Motion to enhance user feedback without distraction.

Performance Optimization - The project prioritizes performance through AVIF image optimization, lazy loading, memoized components, and custom hooks that minimize unnecessary computations.

Narrative-Driven Experience - Scroll-based storytelling is carefully structured, with key narrative elements revealed at deliberate points to reinforce the overall brand message.
